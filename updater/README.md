# DigitalTV Update Checker

This optional companion app checks a public GitHub repository for DigitalTV launcher releases. It downloads a release only after a user requests a check (or enables the optional daily check), verifies the manifest, package name, version, and APK SHA-256, then asks Android to handle installation. Android always shows its own confirmation; this app cannot install silently.

## Prepare a fork

The workflow in `.github/workflows/release-android.yml` runs when a `v*` tag is pushed. In the repository's GitHub Actions secrets, set `RELEASE_KEYSTORE_BASE64`, `RELEASE_STORE_PASSWORD`, `RELEASE_KEY_ALIAS`, and `RELEASE_KEY_PASSWORD`. Keep the signing key and passwords private and backed up: future launcher APKs must use the same key to install as updates.

The workflow builds the launcher and updater APKs and attaches them with `update-manifest.json` to the GitHub Release. In the updater, enter your GitHub account and repository. Release version codes are incremented by the workflow run number.

## Local verification

Build the debug app with `gradlew assembleDebug`. The test release manifest is generated by `tools/make_update_manifest.py`; a debug-only local URL field supports end-to-end testing against an emulator without using a public release.
